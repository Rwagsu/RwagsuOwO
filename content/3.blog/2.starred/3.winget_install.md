嗯...... 习惯了(

对于大多数应用内下载的软件其实是通用做法, 到时候自己转换就行(

::steps{:level="2"}
## 准备
首先在终端正常下载包, 比如:

```powershell
winget install "Godot Engine"
```

直到看到正在下载, 然后按下 :shortcut{value="Ctrl"} :shortcut{value="C"} 取消下载, 然后复制上面显示的下载链接.

![终端页面, 现在正在下载软件包](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251111160934849.png)

## 下载包
使用你所知道的任何更快的方法下载该链接指向的软件包, 比如:
- 兄弟, [Motrix](https://motrix.app/zh-CN/)!
- [NDM](https://neatdownloadmanager.com/index.php/en/) 也不错!

:read-more{title="Bangbang93 实在是太厉害了! 🤓👆" to="https://www.bilibili.com/opus/1133920547856449542"}

如果该软件包来自 GitHub, 你还可以自己从网络上寻找 GitHub 加速下载工具来对 GitHub 链接进行加速:
- [GH Proxy](https://gh-proxy.com/) (非常快)
- [GitHub Proxy](https://github.akams.cn/) (节点非常多且可能比上一个还快)

![正在使用 Motrix 下载文件](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251111164141145.png)

## 打开 Temp 目录.
按下快捷键 :shortcut{value="Win"} :shortcut{value="R"}, 输入 `%temp%` 并回车.

::alert{type="warning" icon="lucide:triangle-alert"}
  虽然不清楚 Temp 文件夹的清理逻辑, 但建议尽快进行下一步操作, 避免文件被删除.

  还有, 憋听营销号胡扯把 Temp 目录里的东西全部删掉, 否则当你的房间变蓝的那一刻, Rwagsu 会赶来把你当夜宵 (๑•̀ㅂ•́)و✧
::

## 进入 WinGet 目录

进入 `WinGet` 目录, 你会看到你刚刚下载的软件包的文件夹.

![WinGet 文件夹, 里面有刚刚的软件包的文件夹](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251111162112379.png)

## 复制软件包
复制刚刚下载的软件包 (憋解压) 到 WinGet 的软件包文件夹内.
![将下载的软件包 (未解压的 Zip 格式) 复制到 刚刚打开的软件包文件夹内](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251111164640503.png)

## 重新运行 WinGet 安装命令
重新运行刚刚的 WinGet 安装命令, 这次它会检测到你已经下载好的软件包, 在校验后将会直接进行安装.

::alert{type="info" icon="lucide:info"}
  我就不装了蛤, 我已经装过了()
::
::

::alert{type="info" title="出错了?" icon="lucide:info"}
  - 有一些人可能无法访问 WinGet 的源, 如果你没有看到 '正在下载' 或之类的提示安装就直接卡住或退出, 你可能需要更换你的 WinGet 源.
  - 你确认你下载的软件包是完整或正确的吗? 只要两个的 SHA 256 不一样, WinGet 就会重新下载软件包.
  - 你确认你打开了正确的 Temp 目录吗? 使用 :shortcut{value="Win"} :shortcut{value="R"} (或在资源管理器的地址栏) 输入 `%temp%` 才是最保险的做法.
  - 你确认你在使用 Windows 系统吗? (你在干什么啊??? 😨😰😱😖😵😫😩😳 Σ(っ °Д °;)っ)
