## 安装

打开冬瓜 HAOS 伴侣(8124 端口)

点击常规维护 > HACS 管理

![HACS01](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251004224925872.png)

这里安装有两个版本:

::tabs
  ::div{label="HACS (可能有网络问题)"}
  你可以直接点击 HACS 安装/修复, 这样安装时就不会有网络问题.

  你也可以在 Home Assistant 的 设置 > 加载项中搜索 HACS, 并安装, 但不一定安装成功, 可能会因为网络问题报错.

  但终究到最后都可能因为 GitHub 访问问题导致无法初始化, 并无法加载商店, 并不适合国内使用, 最好还是选择极速版.
  ::

  ::div{label="HACS 极速版 (更适合中国宝宝体质(喜))"}
  你可以直接点击 HACS 安装/修复, 这样安装时就不会有网络问题. (虽然是极速版, 但是在加载项安装可能会有 DNS 问题.)
