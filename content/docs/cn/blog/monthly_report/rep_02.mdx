### shadcn-docs-nuxt

虽然搬出去了, 但是依然是我非常喜欢的文档网站框架qwq

✅ shadcn-docs-nuxt 拥有和 shadcn/ui 官方网站同款的 UI, 并且附带非常丰富的控件

✅ 并且使用 MDC, 真的是个非常简洁的 Markdown 扩展语法()

✅ 最主要的是, 它有超多超多的组件, 还有一大堆的预设 Frontmatter, 真的很不错 (o´▽`o)

不过嘛......

❌ shadcn-docs-nuxt 要求 **生成静态网站时** 每个页面都必须有对应的本地化页面文件, 也就是说你在 cn 写了一个文档, en 就必须有, 否则会在 `pnpm run generate` 阶段直接报错且不可忽略, 强制忽略能让整个网站都要崩掉 😭

❌ 而且 shadcn-docs-nuxt 的文档部署在 Vercel 上, 用的 Vercel 的 `vercel.app` 域名, 差不多是...... 中国红()

❌ 最主要的是, Nuxt 的字体会主动访问 Google 以获取字体和图标, 虽然你把这两个关掉, 但还会引发一个证书或超时问题(node.js 无法验证代理的证书导致, 如果你没代理就是超时), 目前还没有什么办法()

❌ 因为一部分超时问题(大部分还是 Nuxt 自己的性能), 这会导致 shadcn-docs-nuxt 的构建速度是真的慢, 比 🐢 还慢 :(

❌ 而且, 这么一个 MDC, 它不支持 WebStorm 😇

总之, shadcn-docs-nuxt 适合不惧网络问题, 喜欢 shadcn/ui 又喜欢网站的预设组件的人, 且他还不用 WebStorm. ;)

### Fumadocs

文档的王, 自定义的神.

由地铁站级别的绿点子的作者制作.

## 问题帮助

### CrossOver 游玩 Changed 不显示

这游戏的 RPGMaker 老得都在 CrossOver 过期了, 肯定不行了()

不过还有个邪门的解决方法:

打开 Changed 目录下的 `Game.ini`, 修改这些内容:

```ini
[Game]
Library=RGSS202E.dll
Scripts=Data\Scripts.rvdata
Title=Changed
RTP=
[Fullscreen++]
Fullscreen=0
FullscreenRatio=0
WindowedRatio=1 # [!code focus]
```

<Callout type="info">
    对了, Changed Special 不受影响, 还没过期()
</Callout>

### Steamcommunity 302 不会用

你只需要把程序放到一个稳妥的位置 (我习惯放到 Users/\<user\>/BashApps 里), 然后运行脚本, 勾选好需要的东西后, 在设置选择开机启动服务 (无 UI), 然后要授权的授权, 重启之后就不用再管了()

或者, 你可以使用我的[快捷指令(没一点技术含量)](https://www.icloud.com/shortcuts/359fe680b22043038b2318a2b6567ca2), 这样就可以优雅♂的启动应用 UI, 不过我的快捷指令说用的绝对路径(就是 Users/\<user\>/BashApps), 别忘了改用户名()

<Callout type="warn">
    如果你在运行 cli 的情况下运行了应用 UI, 那么在你关掉 UI 后, cli 貌似也会跟着关掉, 这点需要注意(￣▽￣)

    一定要放稳妥, 开机启动设置好之后这个文件夹就不能动了, 否则代理直接消失, 又要重来一遍. (QAQ)
</Callout>
