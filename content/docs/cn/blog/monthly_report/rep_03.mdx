## 问题帮助

### 调整 Stretchly 的休息提醒时间

Stretchly 是一个开源的休息提醒软件.

但其实, 它的 10 秒后进入休息的提醒是可以改的()

你只需要更改它的配置文件即可 :)

macOS 可以在这里找到它的配置文件: `/Users/rwagsu/Library/Application Support/Stretchly/config.json`

Windows 我不知道, 但你可以在 Everything 搜索 Stretchly 文件夹, 不出意外的话它应该在 AppData 里面, 并且里面应该有个 `config.json`.

打开 `config.json`, 找到这两个属性, 改掉它就好了()

- `breakNotificationInterval`, 它代表长休息前剩余多少时间提醒你, 1000 为 1 秒.
- `microbreakNotificationInterval`, 它代表短休息前剩余多少时间提醒你, 1000 为 1 秒.

就像这样更改它:

```json
{
    "breakNotificationInterval": 10000, // [!code --]
    "microbreakNotificationInterval": 10000, // [!code --]

    // TO

    "breakNotificationInterval": 60000, // [!code ++]
    "microbreakNotificationInterval": 60000, // [!code ++]
}
```

这样, 你就会在休息前 1 分钟提醒你, 而不是 10 秒了 :)

### 去除 macOS 的应用的附加属性

很简单的, 一条命令搞定()

```zsh
sudo xattr -rd com.apple.quarantine <你的 App 路径, 你可以将 App 拖拽到终端窗口来生成路径>
```

此时你需要输入你的 Mac 的密码, 输入的字符不会显示, 你尽管打就好 😇

此时你大概就能直接打开你的应用了()

顺便在这里说一下, 如果你需要打开 macOS 设置中的 "任何来源" 选项, 你可以在终端输入 `sudo spctl --master-disable` 来启用它, 也需要输入密码()

<Callout type="info" title="为什么没有去除附加属性的快捷指令?">
    啊做不出来呗 ()

    即使以管理员运行且使用了 `sudo`, 也会拒绝访问 ()

    不过还是建议大家在去除附加属性时使用 `sudo xattr -rd com.apple.quarantine` 而不是 `sudo xattr -cr`, 要是清除个有用的属性, 那不完了 😰
</Callout>

## 其它

### Logic Pro 12 中我认为最有用的新功能

#### 大分轨拆乐器

首先就是大分轨拆乐器.

它会将你的一段音频的各个乐器通过分析拆成多个轨道, 可以拆成: 人声, 鼓, 贝斯, 吉他, 钢琴, 其它.

这个功能简直绝了! 以后你扒谱再也不用费力气听力 (喜)

你只需要右键音频段落, 右键 > 处理 > 大分轨拆乐器, 等它分析完就好了 (｡･ω･｡)

图片展示不如自己尝试(反正一个图片又不能展示什么), 推荐自己去看看awa

#### 分析和弦

其次就是分析和弦.

也是一个非常好的功能, 这样你就不用费力气听和弦力 (喜)

这样的话, 轻松学习不是梦 x)

你只需要右键音频段落 > 和弦 > 分析和弦, 就可以坐和放宽了 (雾)

或者你直接把音频拖拽到和弦轨道上, 也可以实现同样的效果()

不过毕竟是 AI 分析, 不一定 100% 准确, 但是达到个 80% 以上还是没问题的()
