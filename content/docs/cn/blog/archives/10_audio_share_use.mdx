    ### 事先准备

    在开始之前, 需要确保:

    - 你的手机和电脑是同一个局域网.
    - 你的电脑防火墙允许 Audio Share 通信.
    - 你的电脑当前输出设备和 Auto Share 音频端点是同一个设备:
    ![Auto Share 设置](https://cdn.jsdmirror.com/gh/DrownedOwO/PublicImages@main/images/20260107210829748.png)
    ![Windows 设置](https://cdn.jsdmirror.com/gh/DrownedOwO/PublicImages@main/images/20260107211137749.png)

    ### 电脑端准备

    1. 打开电脑端 Audio Share, 选择一个主机.
    ![选择主机](https://cdn.jsdmirror.com/gh/DrownedOwO/PublicImages@main/images/20260107211526375.png)

    <Callout type="warn">
        官方建议主机直接保持默认即可, 但在我这里无法连接😅, 可能大多数人都是这个情况.
  
        最推荐的做法是选择你电脑自己的 IP.
  
        通过此方法查询你的 IP:
        1. 打开 CMD (按下快捷键 <kbd>Win</kbd> <kbd>R</kbd> 输入 cmd, 然后回车)
        2. 输入 `ipconfig` 然后回车
        3. 你会看到很多个网络适配器, 一般来说, 你在使用哪个网络适配器上网, 你就应该选择那个. <br/>
        我正在使用 WIFI, 所以我选择**无线局域网适配器 WLAN**, 我的 IP 是 `192.168.1.103`.
        ![CMD ipconfig 命令结果](https://cdn.jsdmirror.com/gh/DrownedOwO/PublicImages@main/images/20260107214827306.png)
    </Callout>

    2. 选择音频端点, 使其和 Windows 当前输出设备保持同步.
    ![Auto Share 设置](https://cdn.jsdmirror.com/gh/DrownedOwO/PublicImages@main/images/20260107210829748.png)

    <Callout type="warn">
        不建议保持默认, 可能会出现无声音或者两边都有声音的问题.
        (被坑过 QAQ)

## Q&A

### 仍然无法连接?

可能是你的 Audio Share 被防火墙拦截了.

可以在这里尝试修复防火墙:
![修复防火墙](https://cdn.jsdmirror.com/gh/DrownedOwO/PublicImages@main/images/20260107220919975.png)

如果还不行, 你需要检查你的端口是否被占用了.

在 CMD 输入:

```bat
netstat -aon | findstr "<端口号>"
```

如果看到输出, 说明你的端口号被占用了.

![查看端口占用](https://cdn.jsdmirror.com/gh/DrownedOwO/PublicImages@main/images/20260107223810664.png)

<Callout type="idea">
    端口也有可能被列入到系统保留端口中, 即使没有看到占用, 也会因为系统保护而拒绝访问.
  
    使用此命令查看系统保留端口:
  
    ```bat
    netsh int ipv4 show excludedportrange protocol=tcp
    ```
  
    如果端口刚好在这个范围内, 建议你换一个端口.
  
    ![查看系统保留端口](https://cdn.jsdmirror.com/gh/DrownedOwO/PublicImages@main/images/20260107223931329.png)
</Callout>

### bind: 在其上下文中，该请求的地址无效。

通常发生在切换网络后.

因为切换网络后 IP 变动, 导致现在选择的 IP 地址无效.

你需要重新选择一个 IP, 同时你手机端选中的 IP 地址也必须与电脑端保持一致.
