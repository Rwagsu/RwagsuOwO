适用范围:
- macOS (特别是 Apple Silicon) 开发者
- 所有 IDE
- 任何使用 .NET 调试器的应用框架
- Godot 测试后发现没这个问题 (喜)

很简单, 更新到 NET 10.0.5 (也就是 SDK 10.0.201) 及以上即可解决()

具体参考这个:

<Card href="https://devblogs.microsoft.com/dotnet/dotnet-10-0-5-oob-release-macos-debugger-fix/" title=".NET 10.0.5 Out-of-Band Release – macOS Debugger Fix">
</Card>

所以当你的 Uno Platform 项目调试崩溃时, 不是 Uno Platform 的问题, 也不是 Rider 的问题, 是 .NET Debugger 的问题 ()

有够离谱的, 当时看见 Uno Platform 变这样差点给提了个 issue 😇
