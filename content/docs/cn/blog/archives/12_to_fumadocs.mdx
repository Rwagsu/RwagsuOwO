    <Step>
        ### shadcn-docs-nuxt

        群友 Far1sh 推荐, 真的好看()

        这是自上面几个以来最好看的, 而且功能超级多, 非常棒! 效果是最棒之一!

        但是嘛......

        1. shadcn-docs-nuxt 要求每个页面都要有一个对应的本地化页面, `pnpm run build` 命令我没试过, 但 `pnpm run generate` (生成用于静态网页的文件) 会直接报错.
        2. shadcn-docs-nuxt 官网用的著名的 vercel.app TIMEOUT 域名, 进不去QAQ
        3. shadcn-docs-nuxt 在开发的时候就老是连接 TIMEOUT 域名, Google 的还是什么的都有, 导致开发速度很慢, 因为要等连接那个()
        4. shadcn-docs-nuxt 官方维护有点慢 :(
        5. WebStorm 不 支 持 MDC
        6. 自定义还是稍显逊色
        7. 目前只找到个 Nuxt Studio 能当 CMS, 老版本 CMS 和这个貌似有兼容问题, 新版本还不支持这个东西

        但是还是掩盖不了它的好()
        1. 使用 Shadcn / ui 保持极致的美观性
        2. 提供丰富的颜色选择界面
        3. 在一堆地方添加自己的东西
        4. 使用 icones 作为图标库, 全的很()
        5. 支持快捷键显示, 还能在任何地方使用主页 ui
        6. MDC 在编写文档时能提供相当的便利性
        7. 支持图像缩放
        8. Vue 支持
        9. 方便的插槽

        最后因为开发太卡, 放弃 :( 但如果你能接受或不接触相关问题, 它非常非常适合你 ;)

        总共有两个网站被我~~骗到~~推到 shadcn-docs-nuxt.

    <Step>
        ### Fumadocs (NOW)

        最自由的文档库, 由 Grok 强力推荐 :)

        那么它的特点是:
        1. 最极致的自定义, 网站的任何东西都随你改, 我把它改成了 GitHub 样, 更改相比前面几个简单很多, Qwen 也会()
        2. 最全的功能, 功能本身还好, 但你可以自己加 Radix UI 和 Shadcn/ui 之类的, 三者可以互不打扰, 想加什么加什么, 甚至 Fluent UI 都理论可加!
        3. 非常不错的 UI, 相比 shadcn-docs-nuxt 还是稍显逊色, 所以只能是非常不错 :(
        4. 超频繁的更新, 堪比地铁站的更新!
        5. 文档中的 AI, 用过 Spaceship 之后我才知道专一 AI 它的好 (Spaceship 那个 AI 太厉害了), 虽然 Fumadocs 和这个比逊色一些, 但还是能查找到一些内容() 
        6. React 支持, 实际和 Vue 差不了多少()
        7. Shadcn/ui 官方文档也在用这个文档库(没想到吧)
        8. 支持 Obsidian 接入(虽然我没试过)
        9. 支持超多 CMS!

        缺点也不少啊QAQ
        1. 至今没搞懂 Fumadocs 在**静态的 Next** 中咋搞 i18n > 还是没搞懂
        2. 自带的可缩放图片要是请求中没图像宽高信息会宕机(jsDelivr CDN 或 GitHub 用户专享, Next 的锅) > 我的网站已解决()
        3. 自定义太多导致主页每个正经的控件, 要自己造
        4. 需要在配置文件中指定每一个外部图片的域名
        5. GitHubInfo 组件要是在前期访问不了整个网站会宕机
        6. 侧边栏排序需要一点时间研究
        7. Next 有可能会抽风刷新失败, 需要手动删除 `.next` 文件夹
        8. 文档页面好像只有侧边栏, 和传统的文档站不太一样(小问题)

        Rwagsu 要累瘫了啊, 已经浪费万把代码在这方面了, 不要换了QAQ
