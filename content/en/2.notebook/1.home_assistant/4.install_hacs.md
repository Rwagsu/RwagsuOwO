## 安装

打开冬瓜 HAOS 伴侣(8124 端口)

点击常规维护 > HACS 管理

![HACS01](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251004224925872.png)

这里安装有两个版本:

::tabs
  ::div{label="HACS (可能有网络问题)"}
  你可以直接点击 HACS 安装/修复, 这样安装时就不会有网络问题.

  你也可以在 Home Assistant 的 设置 > 加载项中搜索 HACS, 并安装, 但不一定安装成功, 可能会因为网络问题报错.

  但终究到最后都可能因为 GitHub 访问问题导致无法初始化, 并无法加载商店, 并不适合国内使用, 最好还是选择极速版.
  ::

  ::div{label="HACS 极速版 (更适合中国宝宝体质(喜))"}
  你可以直接点击 HACS 安装/修复, 这样安装时就不会有网络问题.

  你也可以在 [HACS 极速版 GitHub](https://github.com/hacs-china) 按照教程安装. (虽然是极速版, 但是在加载项安装仍可能会有 DNS 问题.)
  ::
::

## 添加集成

在安装好后, 重启 HAOS, 进入 Home Assistant主页面, 转到设置 > 设备与服务.

![HACS02](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251005132115455.png)

转到集成 > 添加集成

搜索 HACS, 并点击 HACS,

::alert{type="info" icon="lucide:info"}
如果你没有看见 HACS, 那就说明你没有安装成功, 请重新按照上面的步骤安装 HACS.
::

![HACS03](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251005140211657.png)

所有的勾全部选择选择! (这些勾对应的知识也很重要, 在安装之前最好学习一下)

::alert{type="info" icon="lucide:info"}
"使用共享的 GitHub 令牌(免登录)" 是 HACS 极速版独有的选项.

它的作用是在你无法访问 GitHub 或没有 GitHub 账号时, 为你提供一个被选项以让你可以在不登录的情况下使用 HACS, 只不过这个令牌还有很多人用.

在此情况下, 你可以选择不勾选:
- 你想要使用自己的 GitHub 账号且有一个可用的 GitHub 账号或有能力注册一个 GitHub账号, 如果有, 还有以下任意一个前提.
- 现在不使用任何代理使用你的计算机, 访问 [GitHub](https://github.com), 如果能够访问, 可以不勾选.
- 你有能力为路由器或 HACS 设置一个能访问 GitHub 的代理.

虽然没满足以上条件也能不勾选, 但能不能进就看你自己了(

## 登录 GitHub

::alert{type="info" icon="lucide:info"}
如果你在前面勾选了 "使用共享的 GitHub 令牌(免登录)", 那么你可以跳过这个步骤.
::

下一步后, 你应该就会看到这个界面, 复制下方的 8 位数代码(就是下面物理打码的那块(doge))

![HACS06](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251005173748758.png)

在 [GitHub 设备激活](https://github.com/login/device/) 中输入 (或者整个复制然后粘贴) 你的 8 位代码(你需要登录你的 GitHub 账号).

![HACS07](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251005173759170.png)

在此处授权你的账号:

![HACS08](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251005173808089.png)

在看到这个页面后就可以返回 Home Assistant HACS安装面板了.

![HACS09](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251005173818690.png)
