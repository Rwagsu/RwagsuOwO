## 检查硬盘占用情况

如果你在使用冬瓜 HAOS, 请打开冬瓜 HAOS 伴侣 (8124 端口) 并查看硬盘占用情况.

如果硬盘占用超过 80%, 且在安装日志中存在关于硬盘容量的警告或报错, 那么卡住就是硬盘问题.

- 如果你在使用虚拟机, 在硬盘设置中扩容到最少 16GB (推荐 32GB或 以上).
- 如果你在使用不可更换硬盘的盒子或系统不在 SD 卡上, 考虑换成电视系统让它继续发扬光大(雾)
- 如果你在使用可更换硬盘或者干脆系统整个在 SD 卡上的主机, 建议更换一块硬盘 / SD 卡.

## 在确认卡住时重启系统

在冬瓜 HAOS 伴侣中的安装进度长时间没有变化且在 Home Assistant 安装界面中无日志变化, 可以尝试通过重启指令或者按下主机自带的关机键, 知道进度条变动, 如果仍然卡住, 再次重启以尝试.

```bash
# 转到 Linux 命令行
login

# 使用 reboot 命令重启
reboot
```

千万不要直接断开虚拟机的电源!!!!!!

如果你的主机的电源按钮的作用是物理断电, 那指定是哪个 "天才厂家" 干的好事(雾) 千万别按, 而是通过自带的 reboot 指令重启.

## 换系统吧(悲)

如果你使用的是官方 Home Assistant OS, 且在安装日志中发现了关于网络问题的报错......

如果你有能力为路由器或 Home Assistant 设置魔法代理, 那么你可以试试, 不保证成功.

如果你没有能力, 那么恭喜你你要为你的盒子拔个卡再重刷一个**冬瓜 HAOS**再插卡再安装并重新按照安装步骤安装或为你的虚拟机换一个**冬瓜 HAOS**的虚拟磁盘并为它扩容到16-32GB+并再次安装🥳🥳🥳.

(简称: 换系统, 换成冬瓜 HAOS)
