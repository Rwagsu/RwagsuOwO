在成功进入 Home Assistant 之后, 你可以通过这几个链接进入 Home Assistant:

- http://homeassistant.local:8123 (Home Assistant 主页)
- http://homeassistant.local:4357 (Home Assistant 状态监控)
- http://homeassistant.local:8124 (冬瓜 HAOS 主页 (冬瓜 HAOS独有))
- http://homeassistant.local:7681 (冬瓜 HAOS 终端 (冬瓜 HAOS独有))

::alert{type="info" icon="lucide:info"}
如果发现 `http://homeassistant.local` 无法进入, 可以尝试将其换成 IP 地址.

1. 查看冬瓜 HAOS 的 IP 地址

  ![HAOS01](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251004200055692.png)

  可以看到是 `192.168.200.129`.

2. 将 `homeassistant.local` 替换成你刚刚查到的 IP 地址, 比如:

  原来的地址: `http://homeassistant.local:8123`

  查到的 IP 地址: `192.168.200.129`

  替换后的地址: `http://192.168.200.129:8123`
::

## 进入到 Linux 命令行

在终端中输入:

```bash
login
```

## 查看安装进度

- 在 `http://homeassistant.local:8123` 查看安装进度, 包括详细的日志.
- 在 `http://homeassistant.local:8124` 查看更详细的安装进度.
-  HAOS 的终端中输入:

```bash
# 上一章节的登录命令
login

# 查看安装进度
ha-install -t
```
::alert{type="info" icon="lucide:info"}
- 敲完每一行命令记得回车.
- 只有冬瓜 HAOS 有 `ha-install` 命令.
::

## 等待安装

就像网页所说, 你需要等待 20 分钟或更长的时间.

::alert{title="卡住了?" type="info" icon="lucide:info"}
- 确认你为 HAOS 分配了足够的空间, 空间太小可能会导致安装完全卡住.
  :br 
  在此处查看空间占用:

  ![HAOS02](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251004201849200.png)

  一般来说, 空间占用不建议高于 70%.

- 一个很玄学的解决方案: 重启 HAOS, 应该就会有所变化.

::alert{type="danger" icon="lucide:circle-x"}
千万不要直接断开虚拟机的电源!!!!!!
::
::

## 安装完成

当你看到这个界面时, 可能并不算安装完成, 如果你直接继续, 可能会卡住, 刷新后 `http://homeassistant.local` 无法访问, 需要换成 IP.

![HAOS03](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251004212057874.png)

如果你看到这个界面(即使没有看到这个弹窗, 只要后面的安装进度全是绿色), 说明安装已经完成, 恭喜 🥳🥳🥳

对了, 如果你看到了这个弹窗, 你需要重启系统后才能配置 Home Assistant.

![HAOS04](https://cdn.jsdelivr.net/gh/DrownedOwO/PublicImages@main/images/20251004212305824.png)
